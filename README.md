# -STM32F407-AIoT-
本项目针对室内微型水族传统投喂盲目、易卡料及残饵导致水体崩坏三大痛点，构建“云—边—端”协同的AIoT全闭环智能养护系统。边缘端以STM32F407为主控，集成水质传感器实时监测，利用双路MaixCAM运行YOLOv11算法量化鱼群饥饿度并识别水位；搭载自研多仓阿基米德螺旋投喂机构，实现毫克级精准混投。系统配套温控、蠕动泵换水及增氧模块实现自动化调控。 云端依托MQTT协议通信，基于Spring Boot接入DeepSeek大模型生成动态投喂方案，结合线性回归预判水质风险，内置熔断逻辑，并配备Web可视化看板支持远程管控与AI咨询。系统具备断网本地自治能力，经72小时满负荷测试验证，可实现7×24小时无人值守稳定运行。
